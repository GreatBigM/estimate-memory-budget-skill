# 算法模型占用登记表

> **查表法专用**：算法模型的工作内存无法由分辨率/码率公式推导，只能按表取数。
> 单位 KB（1 KB = 1024 B）。只登记**运行时工作内存**，不登记 flash 上的模型文件大小
> （例如 4K-WiFi `algo.img` 860KB 是存储占用，不是内存占用）。

## 用法

1. 第 3 步问「算法模型」时，按平台过滤本表，把匹配项作为多选项（可同时选多个）。
2. 选中项 KB 求和，填入 spec 的 `features.npu_algo.algo_model_kb`。
   若该行备注写「已含在池内」，则 `algo_model_kb` 填 0，只计池大小，避免双算。
3. 用户提供表里没有的模型：按「名称 / 平台 / KB / 来源」追加一行，来源写「用户提供（待实测）」，
   同时在聊天里标注该值未经实测。
4. 新登记行要写日期；同算法同上限值的不同产品可另起一行，不要覆盖原行。

## 命名约定

算法名带使用场景前缀，便于按产品形态筛选：

- `【常电】` — 持续供电，算法常驻（如人/车检测）
- `【低功耗】` — 电池/AOV，按唤醒运行
- `【海外】` — 仅海外版本启用的算法

## 待登记

- 同款算法换产品时，先确认计入位置：池外单列，还是已含在 NPU/CMA 池内。
